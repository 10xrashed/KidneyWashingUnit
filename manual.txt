SYSTEM OVERVIEW
===============

This project consists of two main components:
1. ESP32 Hardware Controller (dialysis-controller.cpp) - Manages sensors, pumps, and safety systems
2. Web Dashboard (dialysis-dashboard.html) - Provides real-time monitoring and control interface

HARDWARE SETUP
===============

Required Components
-------------------

ESP32 Development Board:
- Main Controller: ESP32 DevKit or similar
- Power Supply: 5V/3A minimum

Sensors:
- DS18B20 Temperature Sensor (Pin 4) - Monitors dialysate temperature
- Flow Sensor (Pin 2) - Measures fluid flow rate (interrupt-capable pin)
- Pressure Sensor (Pin 34) - Analog pressure monitoring
- Conductivity Sensor (Pin 35) - Measures solution conductivity

Actuators & Controls:
- Water Pump Relay (Pin 18) - Controls main circulation pump
- Heater Relay (Pin 19) - Temperature control
- Solenoid Valve A (Pin 21) - Solution A control
- Solenoid Valve B (Pin 22) - Solution B control

User Interface:
- 16x2 LCD Display (I2C, Address 0x27) - Local status display
- Push Button (Pin 0) - Start/Stop system
- Buzzer (Pin 23) - Audio alerts
- Status LEDs: Green (Pin 25), Red (Pin 26)

Wiring Diagram
--------------

ESP32 Pin Layout:
├── Pin 2  → Flow Sensor (Interrupt)
├── Pin 4  → DS18B20 Temperature Sensor
├── Pin 0  → Start/Stop Button (Pull-up)
├── Pin 18 → Pump Relay (Active LOW)
├── Pin 19 → Heater Relay (Active LOW)
├── Pin 21 → Solenoid Valve A (Active LOW)
├── Pin 22 → Solenoid Valve B (Active LOW)
├── Pin 23 → Buzzer
├── Pin 25 → Green LED (System Running)
├── Pin 26 → Red LED (System Error)
├── Pin 34 → Pressure Sensor (Analog)
├── Pin 35 → Conductivity Sensor (Analog)
└── I2C    → LCD Display (SDA/SCL)

Normal Operation
----------------

- Target: 37°C ± 0.5°C
- Heater Control: Automatic with hysteresis
- Safety: Shuts down if temperature exceeds 38°C or drops below 16°C

Flow Control:
- Solution A: 1000mL target volume

- Automatic Switching: A → B → Stop

Pressure Monitoring:
- Normal Range: 50-300 kPa
- High Pressure Alarm: >350 kPa triggers shutdown

Conductivity Monitoring:
- Normal Range: 13-15 µS/cm
- Critical Parameter: Affects dialysate quality
